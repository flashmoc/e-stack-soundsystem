# Simulations

Zone dédiée à l’optimisation numérique du système à partir des réponses complexes REW.

À terme :
- crossover optimization,
- phase/group delay,
- directivity,
- spatial robustness,
- gain/PEQ search,
- comparaison IIR/FIR,
- scoring multi-critères.

Principe : simuler de nombreux candidats, documenter le ranking, puis ne valider physiquement que les meilleures solutions.
